## Required edits

1. **A5.3.3 — retain low-rank nonzero blocks.** Replace “numerical rank below the smaller block dimension” with **numerical rank zero** as the rank-degenerate exclusion. Low rank alone must not exclude a rotation pair; retain the full realised spectrum without truncation and audit post-rounding rank within ±1 at relative tolerance 1e-3. State that this definition resolves the ambiguous “rank-degenerate” wording in the copied A5.3 rotation block under the chair's endorsed interpretation. Keep non-2D/zero/unsupported/single-matrix-chain rules and full exclusion accounting separate. Otherwise the primary LoRA cohort can be removed by design. For provenance, the *local* `feat/rotation-controls` ref inspected here is `7dea123c61c229e33c357d3847345d260560b116`; its `exclusion_reason` still uses rank below minimum dimension. That local ref does not demonstrate the user-described correction; the eventual frozen implementation must match the endorsed rank-zero rule. No implementation was changed in this review.

2. **A5.4.2 — distinguish a zero log ratio from an invalid ratio.** Positive finite equal losses give L=log(1)=0 and C=0, a valid null estimate. Remove “Zero … log ratios” from the invalidity predicate. Reject nonpositive/nonfinite loss ratios, guarded near-zero losses and invalid studentising variances instead. State the numerical guard unambiguously as A_x/n ≤1e-12 for each arm, with n the number of sampled logical rows including component multiplicities, for the point estimate and every draw. Equality at that guard is invalid; L=0 is not. A truly degenerate standard error remains unresolved under the existing policy.

3. **A5.6.1 and A5.7.1 — finish inference for the non-ratio endpoints.** A5.4.2 supplies a log loss-ratio studentiser; it does not define a studentiser for G7's mean signed intact-minus-rotated response. Supply the component/item influence or resampling construction for that mean, its point/replicate standard errors and failure policy, without applying positive-loss/log-denominator guards to signed responses. For G8, define the paired savings estimand and aggregation, final-score endpoint/unit underlying “percentage point”, qualifying-proposal/guardrail predicates, and episode-clustered intervals including the one-sided missed-proposal bound. Identify the target and evaluation population for critic residual-MAE and its matched comparator predictions. Specify development-only sizing/calibration for those procedures and distinguish rejection-test power from probability of satisfying every point-threshold decision, as A2.3 does. G5-dependent counts/budgets may be filled later before G8; the statistical rules cannot remain generic “paired inference”.

4. **A5.8.3, A5.4.2 and A5.5.1 — make control eligibility and validity total.** “Failure to destroy a sufficient compatible field” has no definition of “sufficient”. Register an outcome-independent statistic and cutoff (including equality), singleton/no-compatible-group handling, required changed-field coverage, and the resulting eligibility action for random/permuted controls. Route inadequate destruction explicitly to unresolved/no funding, rather than letting a positive control interval substitute for successful destruction. Also name the minimum component count and how undefined control/secondary statistics affect each gate: a failed descriptive-only arm must not ambiguously invalidate an otherwise defined primary family, while failure of C, C_abl, C_rand or C_perm must block primary funding. Preserve the existing strict positive bounds on **both conditional and joint** intervals for all three controls.

5. **A5.3.1–2 — complete the selection/calibration contract.** “Integer rank cutpoints” needs the exact floor/ceiling formula and order of global component deduplication versus cell selection; define which row represents a component spanning multiple candidate cells. Pin reproducible simulation code/config specifying the chance-sign null, alternative sign effect, covariance/noise generation, resolution-dependent missingness and audit/selection mechanism. A list of scenarios plus a seed is not an executable simulation. Demonstrate null calibration with the *complete* selected/resolved procedure despite shared field/items before new variant scoring; do not infer independent Bernoulli signs from source closure alone. Preserve 4,000 simulation panels/common paired bootstrap draws, the >0.07 failure action, power uncertainty and no empirical pass claim until the report exists. Define the information-access schedule for development inputs used to set those assumptions.

6. **A5.1.1, A5.2.1–2, A5.3.1, A5.3.4 and A5.10 — complete and pin the acceptance package.** Supply the forty component/row IDs, closure/alias/tensor-coverage proofs, panel/text-group identities and disjointness, exact predecessors, original/reference run identities, all eight alias reuse proofs, missing original/reference counts n_D/n_P, and enumerated reference costs/retry/preprocessing accounting.
