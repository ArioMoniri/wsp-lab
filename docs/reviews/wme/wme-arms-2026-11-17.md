## BLUF

- **All six competitor arms are built** behind the one shared `BudgetLedger` and `BUNDLE_DEFINITION`:
  - Fugu-style reader team;
  - WSR-style single reader;
  - scripted reader;
  - LoRA SFT;
  - best-of-N steering;
  - WM greedy one-step.

  They sit in a registry of all 11 E2 arms (2 primary + the Holm family of 9). Each arm declares its information
  access and training exposure, and the arm context **enforces** the declaration: an undeclared resource raises, every
  resource passes the R0 guard, and there is one store per (arm, episode) that only its owner can read.
- **Readers.** Providers are pluggable through one `complete()` interface. There is an offline `MockClient` and CLI
  clients for Claude, Codex and Gemini (OpenCode).
  - **Tokens:** a hard-capped ledger per arm and episode.
  - **Failures:** truncation, provider errors, cap exhaustion and unparseable output are all failures. A failed round
    forfeits its b bundles, with no retry, repair or fallback.
- **Real smoke: 12,010 tokens of 20,000.** Six Claude calls (claude-haiku-5-5) on a synthetic pool:
  - a probe;
  - one WSR round;
  - one team round, which took the REVISE path.

  All calls parsed, none was truncated, and every count was provider-reported. Codex and Gemini were **not called**:
  Codex's CLI carries about 17.8k input tokens per call (from a local session log), and OpenCode's overhead is
  unmeasured, so neither fits a guaranteed 20k total.
- **Vocabulary-row field.** It never forms a vocabulary-sized covariance. Each approximation is declared, matches
  brute force on a toy, and is shared by every arm:
  - **lm_head:** *projected K-FAC*, exactly the R-block of K-FAC G;
  - **embed_tokens:** *row-diagonal* per-token Fisher.

  Rows outside the declared support, and non-vocabulary tensors, are marked unsupported (`q = None`), never 0. Tied
  embeddings are refused (checked on the real 0.8B).
- **27B separation (condition 13).** Each of these is built and tested:
  - fresh salt `wme-c27` and namespace `wme-bank27`;
  - item exclusion by **manifest identity** for wme-c1 (sealed included), both pilots and the calibration reads;
    a missing manifest raises;
  - root exclusion by J2–J5, including both calibration timing edits;
  - 27B-only primary selection, with a provenance check;
  - a tuning guard that rejects any 9B test, generation, winner-test or sealed source;
  - a read guard on 9B outcome locations, including through symlinks;
  - the two 2-layer-group field configuration (items ≤ 768 tokens);
  - a launch gate.
- **Tests:** 86 new CPU tests and 2 GPU smoke tests, all passing. The full suite has 1,998 passing; the only 3
  failures are the pinned tripwires (§7).
- **A real bug found by a test:** on CPU, `LoRA.factors()` returns views of the live parameters, so checkpoint
  snapshots silently aliased the final weights. Snapshots now clone.

## 4. Field coverage for vocabulary-row roots

**lm_head: `projected_kfac`.**
- A = E[x xᵀ] (hidden²).
- G_R = E[δ_R δ_Rᵀ], where δ_R is the logit gradient restricted to the declared rows **before** any outer product.
- On a 23-token toy this equals the R-block of the full K-FAC G. q for a row_scale edit equals the full K-FAC q
  (rel 1e-4).

**embed_tokens: `row_diagonal`.**
- D[r, i] = Σ_{p: t_p = r} δ_{p,i}² / n, with δ_{p,i} the gradient at the embedding output.
- It equals brute force on the toy.

**Shared conventions.**
- Both follow the support collector's estimator: per-item gradient pass, then a model-sampled Fisher pass seeded
  `response_field.SEED`, with fp32 sums.
- **Not set to zero:** an edit touching any undeclared row, or a non-vocabulary tensor, returns `signed = q = None`
  and `supported = False`, with a reason.

**Declared rows (planned).**

| Tensor | Rows | Source |
|---|---|---|
| lm_head | 256 | 8 row_scale roots × 32 rows |
| embed | 352 | 8 roots × 32 rows, plus the 3 × 32 inert dead rows |

- The inert dead rows have an exact zero field; that is a true 0, not an unsupported 0.
- The row sets are realised from construction token frequencies at bank build, and the `DeclaredRows` identity hash
  is recorded then.
- Limits: |R| < vocabulary and ≤ 4,096.

**One field for every arm.** `SHARED_FIELD_SPEC` names both the support collector schema and this one. Every
`ArmSpec` carries it, and a test asserts that every arm reading the field or descriptions uses it.

## 8. Implementation choices the PREREG author or Board A must ratify

1. **Failure rule for readers.** A failed round forfeits its b bundles. There is no fallback ranking, because a
   fallback would turn reader failure into random-arm performance.
2. **Fugu-style workflow.** Fixed Thinker → Worker → Verifier order with at most one revision and per-role output
   limits (512, 1,024 and 512 tokens). The access lists are in §2.
3. **Scripted-reader rule.** As frozen in its docstring: breach avoidance, then incumbent overlap, then contrast
   match, then oriented field a, then norm.
4. **Pool composition.** 50% mutations of the top 4 own feasible incumbents, presented in a seeded shuffled order;
   the random arm takes the first b.
5. **WM greedy one-step** always extends the base as well as the incumbents.
6. **Best-of-N steering grid.** All 32 layers × 4 contrasts × 4 shifts.
7. **LoRA SFT** uses one adapter seed per episode and checkpoints evenly spaced to the final step.
8. **Vocabulary-row approximations** (§4), and the declared-row rule including the dead rows.
9. **J3 and J4 across models.** They are applied only within a model, since 9B and 27B tensors and residual spaces
   differ; J2 (shared items) and J5 apply across models.
10. **Provider choice for the registered LLM arms.** With a 20k-scale per-episode cap, only the Claude CLI fits
    (about 0.5k tokens per-call overhead). Codex's roughly 18k per-call overhead would exhaust a cap in one call.
