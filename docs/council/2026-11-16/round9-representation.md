## Q3: which literature transfers?

**DWSNets, NFN, NFT — borrow parameter sharing; defer full-weight processing.** [DWSNets (2023)](https://arxiv.org/html/2301.12780v2) characterize permutation-equivariant affine maps for MLP weights. [NFNs (2023)](https://arxiv.org/html/2302.14040v3) process weights/gradients with equivariant layers, demonstrating classifier generalization prediction, masks and INR editing. [NFT (2023)](https://arxiv.org/html/2305.13546v1) adds equivariant attention, evaluated on feedforward MLP/CNN tasks. None of these results establishes edit-outcome forecasting for a fixed hybrid 9B instruct model.

Here every trajectory starts at the same checkpoint: learn changes relative to that base, retaining neuron orientation. Arbitrarily pooling away coordinates could erase useful alignment with base activations/gradients. A dense 16-channel fp32 representation of 9 billion scalar weights alone would occupy **576 GB**, calculated before gradients or optimizer state. Sharing parameters does not remove activation/storage costs. Use writer-level tokens or low-rank edit contractions; an ordinary transformer over those tokens is NFT-inspired, not an exact NFT implementation.

**Graph metanetworks — second choice at coarse resolution.** [GMN (2023)](https://arxiv.org/html/2312.04501v2) handles attention, residual and normalization structure through parameter graphs, with accuracy-prediction and INR experiments. That is a better architectural match than a plain MLP symmetry specification, but a scalar-parameter graph is still too large. Propose a graph with the 64 audited writers from `RoleMap.writers()`, residual-depth edges and same-block mixer/MLP edges. Shared message passing conditions on layer, writer role and mixer type. This is a deliberately lossy graph surrogate; it inherits no full-GMN expressivity theorem.

**Universal Neural Functionals — symmetry audit, optional adapter experiment.** [UNF (2024)](https://arxiv.org/html/2402.05232v1) automatically constructs equivariant maps for weight spaces including recurrence/residual constraints, and tests RNN generalization and learned optimizers on small models. Use it to specify coupled permutations correctly, especially paired gated-MLP channels. Do not independently permute residual coordinates, tied tensors or recurrent channels. An adapter-only UNF must respect the LoRA factor gauge: `(B,A)` and `(BQ,Q⁻¹A)` encode the same delta. Prefer features of `BA` computed via contractions; raw factor entries can encode an arbitrary gauge.

**Hypernetwork/learned-optimizer forecasting — target mismatch.** [HyperNet Fields (2024/2025)](https://arxiv.org/html/2412.17040v1) learns optimization trajectories using gradient consistency, demonstrated for personalized image generation and shape reconstruction. WM-E already knows the realised weight transition exactly; predicting weights wastes capacity. Borrow derivative-supervised consistency for the unknown response only. [The 2023 independent VeLO evaluation](https://proceedings.mlr.press/v239/rezk23a.html) finds tuning and generalization limitations, so optimizer meta-training is not the first contingency. Optimizer moments belong in state only if actions actually perform optimizer updates; fixed task-vector additions have no hidden optimizer history.

**Fine-tuning-outcome predictors — closest methodological transfer.** [GradEx (2024)](https://arxiv.org/html/2409.19458v1) first multitask-trains a meta-initialization, then uses functional values/gradients there to approximate subset fine-tuning losses. It is not a zero-cost prediction from arbitrary untouched weights. Borrow projected-gradient features and a local response surrogate, charging the initialization/training cost if reproducing the method. [When Scale is Fixed (2025)](https://arxiv.org/html/2504.12491v2), initially titled *Can Pre-training Indicators Reliably Predict Fine-tuning Outcomes of LLMs?*, compares fixed-size pretraining variants and finds perplexity inadequate. Its checkpoint-ranking setting differs from editing one checkpoint: use task-specific probes rather than a single global weight statistic; do not claim its predictor transfers.

**Influence, TRAK, datamodels — distinguish data interventions from known edits.** [EK-FAC influence (2023)](https://arxiv.org/pdf/2308.03296) scales training-data influence analysis to large LMs. For a known applied delta `D`, first-order response is `g_evalᵀD`; inverse curvature is appropriate when inferring a training-induced delta, not automatically when scoring one already supplied. Existing K-FAC curvature contractions are not EK-FAC inverse-Hessian influence estimates.

[TRAK (2023)](https://proceedings.mlr.press/v202/park23c/park23c.pdf) uses projected gradients/kernel features for data attribution; [datamodels (2022 foundational exception)](https://arxiv.org/abs/2202.00622) predicts retraining outcomes from dataset-subset indicators. Neither directly predicts arbitrary projection/scaling actions. Avoid a retrained-model zoo. [LESS (2024)](https://arxiv.org/html/2402.04333v2) is more relevant to constructing LoRA directions: optimizer-aware, low-rank gradient similarity with warmup checkpoints. [A Critical Look (2026)](https://arxiv.org/html/2602.14696v2) explicitly separates representation from selection. Accordingly test gradient features with a fixed selector before attributing gains to planning. Warmup/edited-checkpoint features are charged R2, not silently R0.

**Model differences/task arithmetic — first choice.** [Tangent-space task arithmetic (2023)](https://arxiv.org/html/2305.12827v3) links editing to functional disentanglement in vision-language models; [TIES (2023)](https://arxiv.org/html/2306.01708v2) identifies magnitude/sign interference in merging. Neither supplies a calibrated nonlinear 9B outcome predictor. Their useful encoder hypotheses are signed task-vector overlaps, support overlap, layerwise conflict and response-space interaction. Keep a ridge/static response-chart baseline: more geometry may remove the apparent need for recurrence.

## Concrete encoder and Q1(a) test

Propose **one frozen feature schema**, capped at 64 scalars per writer: realised relative norms/rounding error; signed contractions against construction-only task vectors; base-objective gradient contractions; support/conflict summaries; and a small fixed random response projection `D_l z⁰_l` on construction probes. For rank-8 LoRA, compute `B(Az)` without materializing a dense delta. Scale/projection actions can use their exact algebra plus the recorded rounding residual. Dense edits require streamed contractions. Preserve cumulative `E_t`, step `D_t`, support masks and overlaps separately. Label missing recurrent curvature explicitly, never zero-fill it as evidence of no curvature.

Build the schema before new outcomes; normalize on training closures only. Fit a token MLP with shared writer weights, then a two-round width-64 coarse graph only if the MLP qualifies. Target the existing tap sketches/per-item responses; compare random projection against equal-width construction-only PCA. Proposed encoder cap: 250,000 trainable parameters per member, verified before fitting. Base probes/gradients independent of the candidate plus CPU contractions are R0; candidate-dependent base JVPs are R1; edited-state taps/gradients are R2 supervision or charged observations. DeltaNet-state summaries may be another construction-probe target, but require kernel-access and overhead validation; the existing residual hook does not expose them.

If Go-T fails, first distinguish unresolved steps from accurate static prediction. Follow the ruling, retaining the six-objective aggregate and reporting controls separately. Increase paired-item precision only by a new declaration on fresh items/roots; larger samples do not prove recurrence helps. No endpoint cherry-picking or repeated gate testing. For deterministic fixed evaluation, equal realised endpoint weights imply equal response. AB/BA order matters only when the realised endpoints differ (state-dependent edit operators/rounding), or evaluation state differs. A synthetic positive control should hide a low-dimensional saturating functional state behind many edit directions; a quadratic response and matched-endpoint paths are negative controls. This tests compression/approximation efficiency, not irreducible physical history.

Use identical source-closure folds, features, labels, ensemble size and tuning budgets for static cumulative, current residual and memory variants. Give static all base/cumulative information, and a separate matched-budget ordered-token static comparator. Train horizons ≤2, test 3–4. Proposed primary gate: paired closure-bootstrap 95% lower bound for error reduction versus the strongest static comparator exceeds 10%; otherwise kill the trajectory superiority claim. Separately require encoder gain over the old encoder with the same dynamics. Quadratic/null controls must show no statistically supported superiority; failed controls invalidate the comparison. Keep zero-edit and matched-endpoint consistency checks. Share the same field nest/shrinkage rule: current raw-field slope summation must not be compared to an independently calibrated F3u nest without reconciling coefficients.

## Q5: ordered contingency and resources

All new thresholds above are proposals requiring declaration before the fresh testing data, independent of pilot 2. No GPU work was run here.

1. **(a) fails:** obey the static ruling; run CPU encoder ablations on training/development material, then one fresh qualification only if commissioning a separately declared study. 2. **(b) fails:** remove slope transport as ruled; use F3u plus a zero-at-base response residual. Representation cannot establish a missing oracle benefit. Keep derivative features only if a fresh fixed-dynamics ablation helps; no per-state gradient bank by default.
