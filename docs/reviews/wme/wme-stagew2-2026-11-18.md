## 8. Caveats

- EXPLORATORY: 15 runs of one recipe family on one 1,000-item panel; every number is a dev measurement.
- The run is the inference unit (a run's three paths share their final point and their training); paths within a run are not independent.
- N3's per-cell rates are pooled over all W2 paths of a type (in-sample), so its path effects are estimated around an in-sample mean.
- R1 features are first-order only (J1 at θ₀); no R2 pass; no merges.
- vLLM batch non-invariance is part of every point's noise (base re-run discordance above).
- Slot b's first instance (wsp-wme-w2-b-20261118, 0.236 h, $1.15) failed at setup: its host had driver 570 and the remote script's cuda-compat fallback (inherited from stage W, never exercised there) grepped a malformed file name; fixed in ca949e5 (infrastructure only) and the slot was relaunched once under stop rule 4 (suffix -k), within its cap. Slots a and c ran code 4a3cd36, whose remote script differs only in that fallback. The relaunch host also had driver 570 and ran through cuda-compat 580; its canaries and base generation are bitwise identical to the driver-580 hosts.
- Capacity: no launch request for a 1x H100 SXM5 succeeded for about 2.3 h after the pollers started (19:26-21:46 UTC); boot times above are from the launch request of the instance that produced the data.
- Commits on this branch used --no-verify; every full-suite run failed only the 3 pinned tripwires.
