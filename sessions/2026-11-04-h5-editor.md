# H5 editor implementation and Board A revision

Branch: feat/h5-editor. Original baseline: 403 CPU tests; merge-main baseline:
416 passed, 8 deselected. Main merged first, retaining main's README.

The original 13 editor tests did not actually replay a logged proposal or demonstrate
sealed absence: the earlier note overstated those checks. Board A's revision adds
`test_logged_replay_delta_meter_and_array_hashes`, which reads completion code from
JSONL and compares independently written delta file hashes and call/sequence/token
totals. Wall-clock measurements are intentionally not compared for identity.
`test_sealed_store_unreachable_and_detector_catches_injection` creates a real sealed
store, checks denied access, and uses positive controls for reachable files and
injected identifiers/path markers. No research results or paid/GPU runs were made.

Probe results now use a bounded typed schema and reduced hidden statistics; raw
ModelOutput objects and payload arrays are excluded from the log. Tests cover
pre-launch shape/layer/position/top-k/byte bounds, exact delta.add shape, missing
models, checkpoint dtype conversion, mandatory allowlists, config-load validation,
content-pinned pools, production gates, total episode caps, hung probe termination,
metadata-oracle denial and stdout exclusion. Limits and deltas fail closed.

Isolation is seccomp/rlimits with only dedicated IPC writes, no filesystem opens or
path stats. The default same-user process is not a separate security principal.
Optional root-launched setuid clears groups and drops uid/gid; production requiring
it refuses unavailable configurations. The root-only test is skipped as ubuntu.
See docs/H5_DESIGN.md for the precise guarantee and threat exclusions.

Model calls moved out of the supervisor into a killable CPU fork worker. Non-CPU model
tensors are explicitly rejected, so GPU production still needs a separately initialized
serving backend. Templates remain unresolved and production-disabled; zoo entries
remain smoke. No claim of production qualification or reproduction is made.
