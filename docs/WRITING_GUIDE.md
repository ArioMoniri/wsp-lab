# Writing guide (for the paper; applied by the humanizer and checked by Board B)

- Say what was done, with numbers, in the past tense; say what it means in the present tense.
- One claim per sentence. Mixed sentence lengths. No sentence starting with "Notably", "Importantly",
  "Interestingly". No "delve", "leverage", "robust" as filler, "a testament to", "in the realm of".
- No bullet lists in the main text; tables and figures carry the structure.
- Cite only what `paper/refs/verified.yaml` marks verified, with the claim phrased as the source supports it.
- Limitations are specific ("the zoo has one base model per size tier") not generic.
- Figures: `docs/FIGURE_STYLE.md` (JEPAWG style). Every figure caption states n, seeds, and the run id.
- Keep a human voice: it is fine to say "we expected X and found Y".
