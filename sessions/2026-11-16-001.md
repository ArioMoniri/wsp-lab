- Synthetic validation design notes (what was learned, development history kept honest):
  - With a functional state as high-dimensional as the edit space, the static cumulative predictor matched the
    world model (WM/static 0.85–1.1). The D3 mechanism needs a low-dimensional functional state reached through
    many edit directions (input rank 2, 4 hidden units, 24 directions): then WM/static 0.50–0.72 over 5 seeds.
  - Slope transport carries the gain (readout-only ablation is worse than static); the trapezoid sum of the
    base-field slopes equals the raw field exactly, which nests the model on the field.
  - The quadratic-quadrature error is path dependent, so the residual is a per-step local correction, not a
    cumulative state readout.
  - The plain outcome-permutation control is not a clean null: the marginal change grows with horizon, both arms
    must cancel a wrong field anchor and that cancellation extrapolates arbitrarily (gains of -0.55 to +0.26 of
    scale). The control used is the exact null of the WM-vs-static contrast: everything beyond the shared R0
    field (outcome residuals and observations) permuted with random signs; both arms then select lambda = 0.
    The plain permutation is reported as a diagnostic.
  - Both arms nest the same raw field and select the same shrinkage grid on held-out horizon <= 2
    trajectories; an outcome-fitted F3u nest would differ between arms under the null.
