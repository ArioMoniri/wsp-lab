# Round 1 — weight reading: preserve the mechanism before changing the predictor

Research position, 5 November 2026. Branch: `council-r1-reading`.

Our biggest mistake is treating evidence that an analyst can identify a particular circuit as evidence that pooled edit summaries should predict arbitrary benchmark deltas. These are different tasks. The blog supports some weight-only structural identification. Its strongest language-model intervention uses forward passes, hidden states, MLP activations, controlled contrasts, and iterative verification. It does not establish H1's benchmark-delta prediction claim. Worse, the representation critique must be specific: our pooled path discards directions, but our M1 token path already retains projected directions and exact layer IDs.

## 1. What the experiments actually demonstrate

1. **Game recognition, strict weight-only success.** Four identically shaped 500→32→32→5 policies, 17,253 weights each; all four game identities recovered with no list of candidate games. Astra sees channel/action semantics and rounded weight text, without tools or environment execution. The strongest clue is spatial concentration of first-layer input weights (paddle location) plus output-action distinctions. This is not unlabeled numbers alone: input coordinates are semantically anchored. Best-of-three PPO training seeds are used, rather than broad sampling of networks. Verified wording: “Every built-in tool was switched off.” [Experiment 1 release](https://github.com/RikiyaT/lm_understand-logs/blob/main/exp1_which_game/README.md)

2. **Diffusion shape recognition, partial success.** Three 160→64→64→144 DDPMs; all three shape classes identified without tools or forward calculations. Output columns encode spatial edge fragments. Astra describes hollow outlines although the models generate filled shapes: recovering a visual class is weaker than predicting the generated distribution. Verified: “drew every shape as an outline”. The clean-image output layout supplies the coordinate semantics. [Experiment 2 release](https://github.com/RikiyaT/lm_understand-logs/blob/main/exp2_diffusion/README.md)

3. **Language/circuit identification from interior blocks, genuine weight-only success.** Four-layer, six-head, width-384 character transformers trained on Python, romaji, or English. Embeddings, positional embeddings, final norm, and output matrix withheld. Python matrix analysis allowed; executing any layer on any real, random, or constructed input forbidden. Six conversations identify the corpus correctly, though reported corpus probabilities are modest. Copy heads: Python 2.1/3.1/3.5; romaji 3.3; English 3.1. The withheld activation ground truth is obtained separately by running repeated random strings; it is not an input to Astra. Important release discrepancy: `scores.json`'s `true_copy_heads` uses a 0.3 threshold, while the post/table use 0.2. The [head measurements](https://github.com/RikiyaT/lm_understand-logs/blob/main/exp3_language/eval/heads.json) support the latter labels; do not blindly read the former as ground truth. Verified release description: “Linear algebra on the weight matrices”. [Protocol and threshold caveat](https://github.com/RikiyaT/lm_understand-logs/blob/main/exp3_language/README.md)

   Operational computation, checked in [python_r0/tool_calls.jsonl](https://github.com/RikiyaT/lm_understand-logs/blob/main/exp3_language/runs/python_r0/tool_calls.jsonl): with output-by-input matrices, centering P=I−11ᵀ/d and norm gains G, it constructs per-head effective q=Wq GP, k=Wk GP, v=Wv GP, o=P Wo; then M=qᵀk/8 and B=ov (head width 64). It computes singular/eigen spectra, trace(MB)/(‖M‖F‖B‖F), query counterpart trace(MBᵀ)/(‖M‖F‖B‖F), and how later QK maps read earlier OV output subspaces. Quote: “Directional composition: key trace(M B), query trace(M B.T)”. It examines first-layer positional modes and later induction paths, including (2,1)←(0,5), (3,1)/(3,5)←(2,2). It also examines MLP read/write alignment, layer-3 output spectra and weight-space clustering/regression. These are weight products, not softmax attention or MLP evaluations. The romaji/English logs similarly inspect head composition and last-block writer spectra; a restricted final-block output subspace is evidence for fewer character distinctions, not a decoded character dictionary. [Romaji code/output](https://github.com/RikiyaT/lm_understand-logs/blob/main/exp3_language/runs/romaji_r0/tool_calls.jsonl), [English code/output](https://github.com/RikiyaT/lm_understand-logs/blob/main/exp3_language/runs/english_r0/tool_calls.jsonl)

4. **Car repair, success with supplied behavioral evidence.** A failing Kinetix policy is supplied together with scene semantics and one recorded episode. One text reply, no tools or new rollouts; subsequent scoring succeeds in all 1,024 episodes. Astra adds a small position/speed-controlled path through units across layers to back up and then hand control back. This is zero *additional* environment feedback, not diagnosis without observed behavior. The post's 3.5% edit is a localized control-program insertion, not a scalar score read from a delta. [Experiment 4 release](https://github.com/RikiyaT/lm_understand-logs/blob/main/exp4_fix_car/README.md)

5. **MinAtar writing, success conditional on explicit task semantics.** From zero weights, game rules/source, channel/action layouts, one-shot text weights implement hand-designed controllers. No data, training, tools, or pre-score environment play. Beats 100M-step PPO on all three games; relative to 500M PPO, Breakout wins strongly, Seaquest loses, Asterix is close. This demonstrates compiling a specified controller into a small architecture; it is not reading hidden downstream capability from a trained LLM's Δ. [Experiment 5 release](https://github.com/RikiyaT/lm_understand-logs/blob/main/exp5_write_from_scratch/README.md)

6. **Go writing, mixed zero-feedback and feedback-assisted success.** CPU sandbox can manipulate zero-initialized 1.48M-parameter network weights but cannot execute it. With 50 metered calls, it beats the equal-sized PPO comparison. One call may play 128 games or evaluate 256 positions; training/fitting and extra search are forbidden. Thus “50 forward passes” is a large batched feedback allowance, not 50 token evaluations. [Experiment 6 release](https://github.com/RikiyaT/lm_understand-logs/blob/main/exp6_go_from_scratch/README.md)

7. **Sycophancy, weight-only failure; activation-assisted success.** Four weights-only attempts cannot reliably map model differences to sycophancy. With attention-only access, succeeds on all three pairs: up to 16 self-authored texts per call, at most 20 runs, no model-output inspection. Middle-layer heads preferentially attend to the suggested answer; illustrated head 10.2 shifts from question numbers to the user's guess. Embedding/output are tied and frozen. After correcting a chat-template issue, Astra uses the original fwd4 states; normalize the mean repetitive-minus-productive residual vector to u_l. For each writer column j, score (u_lᵀW_l[:,j]) times mean repetitive-minus-productive MLP activation of neuron j; choose the top 64. The eventual layer-15/19 edit is W'_l=W_l−6u_l[mask64⊙(u_lᵀW_l)]. This is rank one **per edited matrix before rounding**, with different layer-specific directions, not evidence of one identical global u. The code uses fwd4 for selection and a second contrast for transfer checks. It tests dose, layer-local, neuron-only and norm-matched random controls, then freezes before practice confirmation. Quote from [final notes](https://github.com/RikiyaT/lm_understand-logs/blob/main/exp8_math/runs/p50c/readable/notes.md): “Unit repetition directions from four matched productive/repetitive original contexts”. ## 2. Mechanisms versus our representation

The successful cases share identifiable structure, but not all share a low-rank mechanism. Games/shapes expose input/output coordinate geometry; controllers use sparse multi-layer programs; induction uses relations between head matrices; Qwen uses activation-identified, low-rank output edits with selected neuron columns. Calling all of this “low rank” erases the distinction that matters.

Our [pooler](../../../src/wsp/features/pool.py) computes 1,242 stats dimensions =18×(1+17×4), plus 136 spectrum dimensions =17×8. Stats preserve four coarse depth buckets; spectra preserve no depth. It averages **changed tensors**, omitting exact-zero effective changes. Empty pools are zero, without an explicit population-count channel. Exact layer identity within a bucket, tensor multiplicity, and pairwise relations are lost. Spectrum inputs are only `record['svd'][:,0]`: every projected singular-vector coordinate is dropped.

Precisely what disappears:

- **Direction identity and sign of the operator:** σ values cannot distinguish equally strong writes into productive versus repetitive residual directions. Stats retain mean/sign fraction and thus are not fully rotation-invariant; nevertheless these few marginals do not recover the operator. Permuting coordinates preserves many summaries while changing their relationship to frozen base weights.
- **Exact circuit location:** exchanging edits within a depth bucket preserves pooled stats. Swapping which head columns are altered is likewise invisible to spectrum summaries.
- **Neuron-column identity and paired readers:** W_down column j must be related to gate/up row j and its activation. Neither total norm nor spectrum identifies this correspondence or whether that neuron fires on relevant inputs.
- **Cross-module composition:** separate spectra of Q/K/V/O do not determine QᵀK, OV, their ordered cross-layer products, or alignment with the residual basis of the base checkpoint.
- **Semantic output anchoring:** neither pooled path explicitly relates a residual write to the unembedding/final norm. This is a useful proposed feature, **not** something Experiment 3 required: its unembedding was withheld. Qwen's decisive direction was identified through activations, not demonstrated as decoded from unembedding weights alone.

But the [extractor](../../../src/wsp/features/extract.py) already stores per-tensor 8×129 tokens [σ,UᵀR64,VᵀR64], tensor names and shape metadata; [data.py](../../../src/wsp/predictor/data.py) supplies exact layer/type IDs; [TensorEncoder](../../../src/wsp/predictor/models/__init__.py) embeds them for M1/M5. M2 uses pooled inputs. Therefore the negative M1 results cannot honestly be explained solely by absent direction/layer information. The remaining gaps include 64-dimensional projection loss, rank-8 truncation, unstable singular bases at repeated/near-zero singular values, no explicit base-frame semantic anchoring, no explicit head/column pairing, and limited labeled samples. Canonical LoRA tokens are saved too, but `data.py` takes `svd`, not `lora`, for tensor tokens. [svd.py](../../../src/wsp/features/svd.py) resolves sign but cannot resolve arbitrary rotations inside degenerate singular subspaces. Its full SVD is not a cheap randomized rank-8 routine. [stats.py](../../../src/wsp/features/stats.py)'s stable-rank field uses only top-eight singular energy, not full Frobenius energy; its entropy likewise describes the retained eight, not the full spectrum.

Which zoo edits contain the relevant structure? [random_dir.py](../../../src/wsp/zoo/random_dir.py) implements ΔW=−αd(dᵀW): rank-one residual writer ablation, shared direction with a specified layer support, but random d has no privileged behavioral meaning. [kernels.py](../../../src/wsp/edits/kernels.py)'s classic abliteration uses refusal directions, interpolated/global or per layer, layer profiles, and optional post-norm gain folding. This is the closest algebraic relative to Qwen, but edits whole supported matrices rather than selecting task-active columns. [ARA](../../../src/wsp/zoo/heretic_ara.py) can be arbitrary-rank and is not this classic kernel; keep the corrected unnormalized variant and excluded unconstrained trials separate ([DECISIONS D6](../../DECISIONS.md)). LoRA has low-rank structure before bf16 rounding but no guarantee of a single behavior direction; task vectors can contain distributed changes; chains mix and accumulate structures ([build.py](../../../src/wsp/zoo/build.py), [lora_sft.py](../../../src/wsp/zoo/lora_sft.py)). Do not equate algebraic low rank with semantic localization. Effective bf16 rounding can increase algebraic rank and erase small changes, including in the blog's selected support.

## 3. Is Δ alone enough? What forward probe is defensible?

For a fixed base, fixed evaluation items, deterministic scoring and fixed execution, the complete Δ mathematically determines the edited model's score. That does not imply a small, learnable sufficient statistic or tractable prediction. Across bases, Δ alone cannot specify a unique behavior: the same write can align with different features. On chains, identical incremental Δ can have different effects after different predecessors. Our formal H1 already allows predecessor features; P3 actually supplies cumulative-from-base deltas, while D5 labels are predecessor-relative ([HYPOTHESIS P4 qualification](../../HYPOTHESIS.md), [DECISIONS D5](../../DECISIONS.md)). Preserve both cumulative state and incremental edit before interpreting a failure as lack of history modeling.

The blog provides positive evidence for structural identification without execution (1–3) and zero-feedback program writing (5 and Go's zero-pass arm). It supplies **no demonstrated predictor of held-out downstream benchmark deltas from Δ alone**. Experiment 7 is a concrete warning that even full weight access and visible differences can be insufficient for the analyst; Experiment 8 and the Gemma failure limit the positive extrapolation. These are empirical failures, not information-theoretic impossibility proofs.

Cheapest useful relaxation: cache module inputs and residual states once on a fixed, public, benchmark-disjoint calibration corpus. For a residual writer, compute v_l,t=ΔW_l x_l,t and direct logit effects z_l,t=U J_N(h_l,t)v_l,t, where U is unembedding and J_N the analytic final-RMSNorm Jacobian evaluated at a fixed cached reference residual. This is a direct-effect logit lens, **not** the downstream Jacobian through intervening blocks. For MLP down_proj, x must be cached **post-gating MLP activation**, not residual h; writing ΔW·h blindly has the wrong domain. Q/K edits affect attention nonlinearly and require frozen-context attention recomputation or a first-order module derivative. Hybrid linear mixers need their actual recurrent state, not an invented QK substitute.

Use 16 fixed 128-token texts as a planned cache, storing each writer's input and corresponding residual (2,048 token positions). Cache the 64 most probable base output tokens per position, and score only those plus a predeclared token group list. Low-rank multiplication costs O(Nr(d_in+d_out)) per matrix versus dense O(Nd_in d_out), plus O(N×64×d_model) per projected residual; shared unembedding projections can be cached. No edited full-model inference per entry; cache creation requires base forwards once. Rank-8 replay misses residual tail energy, so record its fraction and compare dense replay on a timed pilot. For chains, base-cache replay is a cumulative-from-base approximation; subtract consecutive feature snapshots for a per-step signal, and explicitly test degradation with drift. A predecessor-state cache would cost additional forwards per predecessor and belongs in a separate budget arm.

This violates literal “no forward pass ever,” so call it **cached-activation-assisted prediction**, separate from H1. It preserves the useful spirit: no benchmark labels, no task-specific editor feedback, no per-candidate generative evaluation. There is no measured probe latency in this repo; [H5_DESIGN](../../H5_DESIGN.md) explicitly requires timing it rather than scaling from a whole evaluation. Report setup and amortized GPU-seconds separately. Nothing justifies asserting a measured seconds-per-entry figure here.

## 4. Proposals, ranked by expected value per GPU-hour

Common protocol: use the existing labeled panel, same outer splits/seeds/ancestry-cluster paired bootstrap and train-only preprocessing from [DECISIONS P4](../../DECISIONS.md). Compare **StatNN on original features**, **StatNN on augmented features**, and a small regularized head on the same augmented features. If trees improve, credit representation; do not claim a new world model. Primary targets: same-device predecessor-relative MMLU-Pro/HellaSwag deltas; KL and log-ppl changes as mechanistic diagnostics, conditional on between-entry variance and reference qualification. Exclude sampled GSM8K/MATH/IFEval, refusal and over-refusal from confirmatory ranking at this tier ([RESULTS seed-1 panel](../../RESULTS.md), [Board A](../../reviews/H5/board-a-prereg-2026-11-04.md)). Repeatability is not population validity; constant small-edit targets do not become rankable by being deterministic.

Cost anchor: existing extraction mean 66 s/entry over 1,235 entries ([PROGRESS P3](../../PROGRESS.md), feature manifest). Thus a full re-extraction is 5.50 device-hours for 300 or 22.64 for 1,235 **if charged as occupied GPU time**; extraction includes CPU work, so these are reservation-equivalent budgets, not measured GPU utilization. Existing-cache analyses avoid this cost. Predictor jobs take 1–10 minutes per brief. All additional caps below are **proposed stop budgets**, not latency measurements; time ten entries before approving a larger extraction. No new benchmark evaluations are needed initially. If labels must be added, the brief's planning input is 0.125 GPU-h/entry locally or 0.0517 effective H100 h/entry, not the probe price.

### Rank 1 — exact-layer scalar baseline from existing files

For each of 24 layers and two residual-writer roles (attention/mixer output, MLP down), concatenate 18 stats, eight singular values, and a presence bit; fixed 24×2×27=**1,296 dimensions**. Zero-pad absent slots; if multiple tensors share a slot, fail schema validation instead of silently averaging. Test the non-writer tensors later. Use the saved tensors and names, no new SVD. This identifies layer localization without requiring a neural head to learn it from projected directions.

Extraction: one O(number-of-saved-records) CPU pass per entry, **zero GPU extraction hours**, versus 66 s if unnecessarily recomputed. Planned GPU predictor cap **0.5 h total** for the first nested three-seed comparison, recording actual use. First targets MMLU-Pro/HellaSwag. Falsifiable planned criterion: original-plus-layer features reduce paired MAE by at least 5% and improve Spearman on both, with ancestry-cluster CI for MAE improvement excluding zero; within-bucket layer shuffling should remove the gain. Failure says location scalars alone do not rescue H1. This is my first experiment.

### Rank 2 — cached-input direct effects, a separate assisted arm

Use the cache and operator above, all 24 layers. For each layer aggregate its residual-writer effects into eight values: mean/RMS perturbation norm, mean cosine with cached residual, mean signed base-top-token logit change, RMS 64-token logit change, mean/max conditional top-64 KL between normalized base and perturbed logits, and mean declared end-token logit change. **24×8=192 dimensions**; keep fixed layer positions. Conditional top-64 KL is a proxy, explicitly not full-vocabulary KL. Freeze texts/token groups before fitting; never select them on held-out labels.

Extraction: no new SVD, rank-8 factors can be reconstructed only approximately from existing projected tokens, so this arm must load Δ and obtain actual factors or use dense Δ multiplication. Reuse exact factors only when they describe effective Δ; unrounded LoRA factors are not sufficient. Pilot dense replay versus an actual rank-8 decomposition. Proposed cap: **66 additional device-seconds/entry including needed factorization**, hence at most **5.50 additional device-hours for 300**, plus **0.25 h cache-creation reservation**; stop if exceeded. Total worst-case fresh baseline+probe is 132 s/entry, 11 h/300; this is a budget ceiling, not a forecast. First predict KL/log-ppl, then MMLU-Pro/HellaSwag. Planned falsifier: at least 10% paired MAE reduction for KL and 5% for each benchmark over original-feature StatNN; if KL improves but benchmark deltas do not, sensitivity estimation has not solved capability prediction.

### Rank 3 — layer/column structure and base-anchored directional sketches

For every down_proj layer compute column energies p_j=‖ΔW[:,j]‖²/‖ΔW‖²; retain top-1/8/64 energy shares, effective column count 1/Σp², and nonzero-column fraction (**five**). For the top eight columns ordered by p_j add cosine(ΔW[:,j],W0[:,j]), cosine with the identically indexed gate row, cosine with up row, and energy p_j (**32**). Empty columns get zeros and a presence bit per selected column (**eight**): **45/layer, 1,080 total**. These row/column vectors all live in residual coordinates; folding norms where necessary must follow the architecture. This retains neuron reader/writer correspondence without claiming neuron IDs transfer across models.

Add a sign/basis-stable operator sketch S_l=R_outᵀΔW_l R_in with fixed seeded 16-column projections. Applied to the two writer roles at 24 layers gives **12,288 dimensions**. Use a fixed 32-dimensional train-fold-only PCA representation in the small predictor, with masks and scalar features retained separately. Unlike separate U/V token signs, S does not change under an equivalent factorization or a rotation of a degenerate singular basis. For semantic anchors replace eight output projection columns by a frozen eight-vector orthonormal basis of declared unembedding token contrasts; normalization included and contrasts selected without benchmark labels. This is base-anchored weight-only analysis, not an activation claim.

Extraction: stream effective Δ and base writers/gate/up matrices, O(number of entries) reductions plus thin matrix products, **no full SVD needed**. Proposed cap **33 extra device-seconds/entry**, half the measured 66 s baseline: **2.75 additional device-hours/300**; fresh combined cap 99 s/entry, 8.25 h/300. First KL/log-ppl, then MMLU-Pro/HellaSwag on localized ablation/LoRA subsets; do not count family classification. Planned falsifier: at least 5% paired benchmark MAE improvement; reader-row permutation or rotation relative to frozen base anchors should destroy that improvement while preserving delta norms. No gain despite adequate feature variance weakens the directional-information explanation.

### Rank 4 — explicit circuit composition, only if earlier arms help

For conventional attention heads construct M_h=Wq,hᵀWk,h/√d_h and B_h=Wo,h Wv,h with norm-gain treatment, before and after the edit. For every ordered earlier/later head pair compute change in normalized trace(M_later B_earlier), trace(M_later B_earlierᵀ), and normalized product Frobenius norm. Aggregate each metric's signed mean, RMS, max and min over head pairs for each layer pair: **12×L_attn(L_attn−1)/2 dimensions**, with actual full-attention layer IDs retained. Compute with low-rank head factors; do not materialize d×d products for every pair. RoPE needs relative-position-specific QK products (freeze a declared lag); gated/linear attention needs a different derivation and is excluded, with an availability mask. This is inspired by Experiment 3, not a direct transplant of its learned absolute-position character model.

Cost is structurally larger than marginal stats and unknown here; proposed **66 extra device-seconds/entry** pilot cap, **5.50 additional device-hours/300**, fresh combined ceiling 132 s/entry. Stop rather than silently escalating. First test conventional-attention-edited entries' KL/HellaSwag; planned falsifier is ≥5% paired MAE reduction over augmented StatNN, and disappearance under head-pair permutation. Failure on a predominantly MLP-edited panel is not a decisive circuit-reading test; demand a sufficient attention-edited panel before spending this budget.

I rank the assisted probe above another large weight encoder because Experiment 7 directly shows the value of input-conditioned routing. I rank existing-cache layer features first because they can falsify the simplest pooling explanation essentially for free. None justifies retraining an SSM first.
