This remains a numerical budget, not proof of the cause of each singular-value crossing.

2. **Registered one-spacing bound — satisfied.** `rounding_bound` uses `min(abs(R), 0.5 ulp_bf16(W+R_eff)) + ulp_fp32(fl32(W+R))`, with fp32 addition followed by bf16 rounding. Sign, binade, tie, cancellation, signed-zero, subnormal, zero-floor, overflow and nonfinite cases are present. A genuine double-rounding example fails the no-slack bound; exact-bound and next-value-outside assertions distinguish the fixed inclusive allowance from a relaxed one. No factor-two slack is accepted.

3. **Pooled norm guard — satisfied under the chair's correction.** The implemented rule is `abs(pooled ||R_eff|| - pooled ||D||) / pooled ||D|| <= 0.5`, where each pooled norm is the square root of summed squared tensor norms. It has both lower and upper boundaries, an independent D reference and finite/coverage checks. Exact and outside-boundary tests, unequal-tensor pooling, a small tensor rounding away, upper-side exclusion, and retained ladder/ledger checks distinguish this from the rejected squared-energy rule. Energy ratio remains a diagnostic. The half-energy wording in the brief has no authority over the registered norm rule.

4. **Reloaded, bit-pattern replay — satisfied.** F10 writes the root delta or chain increment/cumulative files, reloads them, reconstructs from fresh per-tensor seed state at four threads, and compares dtype, shape and integer bit patterns.
